# Raiders Damage Calculator

Fan-made build calculator for Splatoon Raiders: player level (50 +N), tank,
weapon + level/upgrades, relics, and gadget power-ups → the per-hit displayed
damage the in-game gear screen shows.

Static site — raw JS + JSON, no build step, no backend. Works on GitHub Pages
or any static host.

Formula reverse-engineered by Laugh_Lover/Delpolo, whose research and
spreadsheet this tool is built on — credited with their blessing:
[GameFAQs thread](https://gamefaqs.gamespot.com/boards/540184-splatoon-raiders/81174710) ·
[spreadsheet](https://docs.google.com/spreadsheets/d/e/2PACX-1vThDUSq-3xSdnngXijX_8sPtEPU2vnnj26uWvLFn5qZmlwnKbl-KDOnJ_2Z0Ix-pdax6XFCW-sl8NmV/pubhtml):

    displayed = (playerDamage + baseWeaponDamage) x attackFactor x tankBonus

then additive bonuses (summed) and multiplicative bonuses on top, per the
thread's stacking rules.

**Live at: <https://rdvansloten.github.io/raiders-calc/>** — every push to
`main` redeploys automatically via GitHub Actions (`.github/workflows/pages.yml`).

## Run locally

    python3 -m http.server 8642
    # open http://localhost:8642

(`file://` won't work — the page fetches the JSON data files.)

## Deploy

Hosted on GitHub Pages with build type "workflow": pushing to `main` runs
`.github/workflows/pages.yml`, which uploads the repo root as-is and deploys.
No build step.

## Layout

- `index.html`, `style.css`, `app.js` — the site
- `data/player_levels.json` — HP + damage for levels 1–50, plus the
  post-softcap rules (+0.5 HP / +2 damage per "50 +N" level, extra caps at 9999)
- `data/weapons/index.json` + `data/weapons/<slug>.json` — one file per weapon
  family: variants, attacks with scaling factors, shared base-damage curve for
  weapon levels 1–100 (level + upgrades caps at 100 total)
- `data/tanks.json` — the three tanks and their relic rules
  (Power: no tactic, max 1 speed · Speed: no power, max 1 tactic ·
  Tactic: no speed, max 1 power)
- `data/relics.json` — relic list (placeholders until real names/values land);
  5 slots, 3 levels each, per-level `levels` percentages feed the additive bonus
- `data/gadgets/` — one JSON per gadget, scraped from Inkipedia
  (`python3 tools/scrape_gadgets.py`); damage-increasing parts only, each with
  star/slot-cost/percent variants, gadgets tied to their tank
- `data/*.csv` — tidy, headered tables generated by `tools/extract.py`:
  `player_levels.csv`, `base_weapon_damage.csv`, `weapon_factors.csv`,
  `weapon_damage_long.csv` (all 3,558 logged observations),
  `spirhalite_costs.csv`, `weapon_list.csv`
- `data/source/laugh_lover_spreadsheet.xlsx` — the complete source workbook
  (all 7 tabs), downloaded verbatim from the published Google Sheet
- `data/source/raw/*.csv` — raw per-tab CSV exports (commentary and all);
  input for the extraction pipeline
- `tools/extract.py` — rebuilds `player_levels.json` and `data/weapons/` from
  the CSVs (median reconstruction across all 3,558 logged cells, outlier/typo
  rejection, per-column factor re-fit)

Rebuild data: `python3 tools/extract.py`

Tank and relic icons are black-circle placeholders until PNGs are provided
(`icon` fields in the JSON are ready to point at image paths).

## Data notes

- Verified round-trip against every logged sheet cell: all but 26 (hand-entry
  typos in the source) agree within ~0.06%; the game's own rounding causes
  ≈0.1% drift at most. Independent check: the thread's 207,413 E-liter full
  charge reproduces as 207,410.
- The sheet's Heavy Splatling factor (0.405) is a 3x transcription error; the
  fitted 0.135 matches all its logged damage.
- Sloshing Machine's explosion factor is 0.36 in the newer relog (0.33 in
  early logs — possibly changed by a patch); the newer value is used.
- Rarity and Primo variants don't affect damage; each weapon trio shares one
  damage curve.
